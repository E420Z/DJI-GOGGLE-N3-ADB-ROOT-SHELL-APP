Sparrow2 is the goggles' radio subsystem. This page reads reports and tool inventories, and can dump the encoded liveview the S2 already sends over its own USB link. There is no transmit, no jamming and no IQ/ADC access — the backend does not expose them.

Receiver capture

S2 video (H.265)

Experimental

Dumps the encoded liveview that the S2 already sends over its USB bulk endpoints (main 0x84 1920×1080, secondary 0x81 640×360). Receive-only: it never starts the link, never re-routes video and never writes outside /data/local/tmp/s2cap. Decoding happens on the PC.

Link start/stop (006E0001/006E0000) is not wired yet — the frame needs a bench run with the aircraft off. Capture works without it.

Safety key

Danger

Hard limits

Read this
  • Never write to /system. It is verified on every boot.
  • dm-verity mode 2 bricks the goggles on the next reboot.
  • There is no known unbrick for the N3. Treat every write as permanent.
  • This app only writes to /vendor and /data/local/tmp.
