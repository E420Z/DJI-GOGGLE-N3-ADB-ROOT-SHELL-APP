Sparrow2 is the goggles' radio subsystem. This page reads reports and tool inventories, and can dump the encoded liveview the S2 already sends over its own USB link. There is no transmit, no jamming and no IQ/ADC access — the backend does not expose them.

Receiver capture

S2 video (H.265)

Experimental

Dumps the encoded liveview that the S2 already sends over its USB bulk endpoints (main 0x84 1920×1080, secondary 0x81 640×360). Receive-only: it never starts the link, never re-routes video and never writes outside /data/local/tmp/s2cap. Decoding happens on the PC.

Not supported on this build. The vendor encoded-capture path needs a read-only system config (or a flash dump), both outside the project safety rules. Use the E420Z display mirror or Goggles Stream for decoded video. Probe still works.

Link start/stop (006E0001/006E0000) is not configured on this build — the start_cmd and finish_cmd arrays in wlm_cfg.json are empty.

Goggles encoder → this PC ExperimentalRead-only

This is the goggles' own vc8000e hardware encoder, read by the vendor MDC reader and sent over the USB link on TCP 5571. The H.264 bitstream is copied into fMP4 with no re-encode, so what you see is exactly what the goggles produced. The page only reads the stream and never changes anything on the goggles.

  • Never write to /system. It is verified on every boot.
  • dm-verity mode 2 bricks the goggles on the next reboot.
  • There is no known unbrick for the N3. Treat every write as permanent.
  • This app only writes to /vendor and /data/local/tmp.
